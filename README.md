# Gestiona-informaci-n-mediante-Software-en-Linea
Repositorio para ejercicios y pruebas de gestiona información mediante uso de Software en Linea
### ventajas
1.**Control de Versiones y Gestión del Código: Basado en Git, permite realizar un seguimiento detallado de los cambios, facilitando volver a versiones anteriores, trabajar en ramas (branches) y fusionar el código de forma segura.** 

2. **Colaboración Simplificada: Facilita el trabajo en equipo mediante Pull Requests, lo que permite revisar el código, hacer comentarios y proponer cambios antes de integrarlos al proyecto principal.**
