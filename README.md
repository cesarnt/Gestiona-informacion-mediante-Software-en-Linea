# Gestiona-informacion-mediante-Software-en-Linea
Repositorio para ejercicios y pruebas de gestiona información mediante uso de Software en Linea

Git Hub

Caracteristicas. ventajas y desventajas

#Caracteristicas#
Control de Versiones con Git: Permite rastrear, revertir y gestionar cambios en el código fuente de proyectos de software.
Alojamiento en la Nube (Repositorios): Almacena proyectos (repositorios) de forma remota, permitiendo el acceso desde cualquier lugar.
Colaboración y Gestión de Equipos: Facilita el trabajo conjunto mediante pull requests, donde los desarrolladores revisan y fusionan código.

#Ventajas#
Control de Versiones y Gestión del Código: Basado en Git, permite realizar un seguimiento detallado de los cambios, facilitando volver a versiones anteriores, trabajar en ramas (branches) y fusionar el código de forma segura.
Colaboración Simplificada: Facilita el trabajo en equipo mediante Pull Requests, lo que permite revisar el código, hacer comentarios y proponer cambios antes de integrarlos al proyecto principal.

#Desventajas#
Privacidad del código: Aunque ofrecen repositorios privados, algunos usuarios desconfían al alojar código propietario en servidores de terceros, prefiriendo soluciones autohospedadas.
Límites de rendimiento: Un alto volumen de operaciones de lectura o procesos automatizados (CI/CD) puede ralentizar el repositorio, con límites recomendados de 15 operaciones por segundo.
